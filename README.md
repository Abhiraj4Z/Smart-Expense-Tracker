# Expense Tracker Web Application

A web-based expense tracker developed to help users manage their expenses, monitor savings, set monthly financial goals, and review their spending activity.

## Features

- **User Authentication:** Sign-up, login, and logout functionality.
- **Expense Management:** Add and manage expense records.
- **Dashboard:** View an overview of financial activity.
- **Expense Analytics:** Review spending patterns and summaries.
- **Monthly Goals:** Set and track monthly financial targets.
- **Savings Management:** Monitor savings and financial progress.
- **Settings:** Manage application preferences.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Installation and Setup

### Prerequisites

- PHP
- MySQL
- A local development environment such as XAMPP or WAMP
- A web browser

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/Abhiraj4Z/Abhiraj.github.io.git
   ```

2. Move the project folder into your local server's web directory. For XAMPP, this is usually `htdocs`.

3. Create a MySQL database for the application.

4. Configure the database connection in `config.php` using your local database settings.

5. Start Apache and MySQL from your local server control panel.

6. Open the application in your browser using the appropriate local URL, for example:

   `http://localhost/Abhiraj.github.io/login.html`

   Adjust the URL if you use a different folder name.

## Security

Keep database credentials out of public repositories. Configure appropriate authentication, input validation, and database access controls before deploying the application.
